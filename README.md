# 電子帳簿保存システム

電子帳簿保存法に対応した電子取引データの管理システム

## 概要

2024年1月から義務化された改正電子帳簿保存法に対応するため、電子取引データを規則に従ってファイル名変更し、検索性を確保して保存するためのPyQt6ベースのGUIアプリケーションです。

### 主な機能

- **PDFプレビュー機能**: ファイルの内容を確認しながら登録作業
- **ドラッグ&ドロップ対応**: 複数PDFファイルを簡単に追加
- **自動ファイル名生成**: `通し番号_発行日_金額_取引先名.pdf` 形式で自動命名
- **OCR文字認識機能**: PDFから金額・日付・取引先名を自動抽出（選択領域対応）
- **和暦自動変換**: 令和6年9月1日 → 20240901 形式に自動変換
- **年度別フォルダ管理**: 年度ごとに自動的にフォルダを作成・整理
- **メタデータ管理**: CSVベースのインデックスファイルで検索性確保
- **設定機能**: 保存先や書類分類のカスタマイズ

## 動作環境

- **Python**: 3.11+
- **GUI Framework**: PyQt6
- **OCR Engine**: Tesseract OCR
- **PDF処理**: PyMuPDF (fitz)

## セットアップ

### 1. 必要な依存関係のインストール

```bash
pip install -r requirements.txt
```

### 2. Tesseract OCRのインストール

#### Windows
1. [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) からインストーラーをダウンロード
2. インストール後、パスを通す
3. 日本語言語データ `jpn.traineddata` をインストール

#### macOS
```bash
brew install tesseract tesseract-lang
```

#### Ubuntu/Debian
```bash
sudo apt-get install tesseract-ocr tesseract-ocr-jpn
```

### 3. アプリケーション起動

```bash
python main.py
```

- **右側パネル**: 
  - PDFプレビュー（ズーム・ページ切替対応）
  - OCR領域選択機能
  - ファイル名プレビュー

### ファイル検索モード（プレースホルダー）

## 使用方法

### ファイル登録の流れ

1. **PDFファイルの追加**
   - メインウィンドウにファイルをドラッグ&ドロップ
   - または「ファイル」→「PDFを開く」

2. **データ入力**
   - ファイルリストからPDFを選択してプレビュー表示
   - OCR機能で自動抽出（領域選択可能）
   - 発行日、金額、取引先名、メモを入力・修正

3. **保存**
   - 「保存して次へ」ボタンをクリック
   - 設定されたルートフォルダ配下の年度別フォルダに自動保存

### OCR機能の使い方
- PDFプレビュー上でマウスドラッグで領域選択
- 選択した領域に対してOCR処理を実行
- 認識結果が該当するフィールドに自動入力

## 設定ファイル

`config.ini` で以下の設定をカスタマイズできます：

```ini
[Paths]
root_save_directory = 電子帳簿保存

[FolderNames]
expenditure = 01.支出情報
income = 02.収入情報
order = 01.注文書・契約書
estimate = 02.見積書(確定版)
invoice = 03.請求書
receipt = 04.領収証

[LastInputs]
year = 2025
doc_type_index = 2
```

## トラブルシューティング

### OCRが正常に動作しない場合
1. Tesseractが正しくインストールされているか確認
2. 日本語言語データ（jpn.traineddata）がインストールされているか確認
3. 画像の解像度や品質を確認

### ファイルが保存されない場合
1. 保存先ディレクトリの書き込み権限を確認
2. ディスク容量が十分にあるか確認
3. ファイル名に使用できない文字が含まれていないか確認
