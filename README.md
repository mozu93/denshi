# 電子帳簿保存システム

**バージョン**: v2.8.0
**最終更新**: 2026-05-25

## 概要

電子帳簿保存システムは、日本の電子帳簿保存法に対応したPyQt6ベースのデスクトップアプリケーションです。PDFファイルのOCR処理、メタデータ抽出、構造化された保存・検索機能を提供します。

## 主な機能

### 1. PDFファイル登録
- フォルダを選択してフォルダ内の全PDFを一括登録
- PDFファイルを個別に選択して登録
- PDFファイルのドラッグ&ドロップ対応
- **自動入力**: テキストPDFから発行日・金額・取引先名を自動抽出
- **OCR手動読み取り**: PDF上でドラッグした範囲をOCRで読み取り（Windows OCR使用）
- **学習機能**: 取引先ごとにOCR読み取り範囲を記憶し、次回から自動適用

### 2. ファイル検索
- 年度・取引区分・書類種別による検索
- 発行日・金額・取引先名・メモによる条件検索
- 複数条件の組み合わせ検索

### 3. データ管理
- CSV形式のインデックス（index.csv）でメタデータを管理
- 年度ごとのファイル整理
- メモ機能による追加情報の保存
- インデックス再構築時のメモ保持

### 4. ネットワーク対応
- ネットワークドライブ上での共有利用対応
- 複数ユーザーでの同時アクセス対応

### 5. 自動アップデート
- 起動時にGitHub Releasesを自動チェック
- アプリ内でインストーラーをダウンロード（プログレスバー表示）
- ダウンロード完了後、ワンクリックでインストール＆自動再起動

### 6. 真実性確保（電子帳簿保存法対応）
- 保存・編集・削除操作の監査ログを自動記録
- ファイルハッシュによる改ざん検知

## インストール

### 方法1: インストーラーを使用（推奨）

1. [GitHub Releases](https://github.com/mozu93/denshi/releases) から最新版のインストーラーをダウンロード
2. インストーラーを実行し、画面の指示に従ってインストール
3. デスクトップのショートカットまたはスタートメニューからアプリケーションを起動

**必須環境**:
- Windows 10/11 (64bit)
- OCR機能は Windows 標準搭載のエンジンを使用するため、追加インストール不要

### 方法2: ソースコードから実行（開発者向け）

**必須環境**:
- Python 3.11以上
- Windows 10/11（Windows OCR に対応）

```bash
pip install -r requirements.txt
python main.py
```

## 使用方法

### ファイル登録

1. **ファイル登録モード**タブを選択
2. PDFを追加する方法を選択:
   - メニュー **「ファイル」→「フォルダを開く」**: フォルダ内の全PDFを一括追加
   - メニュー **「ファイル」→「ファイルを開く」**: PDFファイルを個別に選択
   - ウィンドウにPDFをドラッグ&ドロップ
3. PDFを選択すると自動入力を試みます（テキストPDFの場合）
4. 必要に応じてメタデータを手動で修正
5. **「保存して次へ」** をクリック

### OCR読み取り（手動）

1. 入力したい項目（発行日・取引先名・金額など）をクリックして選択
2. 右のPDFプレビュー上で読み取りたい範囲をドラッグ
3. OCRが自動実行されて結果が入力されます

> OCR結果はページ表示と並行してバックグラウンドで取得されます。初回選択時に数秒かかる場合があります。

### ファイル検索

1. **ファイル検索モード**タブを選択
2. 検索条件を入力（複数条件指定可能）
3. **「検索実行」** をクリック（Enterキーでも実行可能）
4. 結果から **「編集」** をクリックしてデータを編集

### インデックス再構築

1. メニューの **「インデックス再構築」** をクリック
2. 確認メッセージで **「はい」** をクリック
3. ファイルシステムをスキャンして index.csv を再構築

**重要**: インデックス再構築時はメモが保持されます。

### 文字サイズの変更

メニュー **「表示」** から文字を大きく・小さく・リセットできます。

### 設定

メニュー **「設定」** からアプリの各種設定を変更できます。

## メニュー構成

| メニュー | 機能 |
|---|---|
| ファイル → フォルダを開く | フォルダ内の全PDFを一括登録 |
| ファイル → ファイルを開く | PDFを個別に選択して登録 |
| ファイル → 終了 | アプリを終了 |
| インデックス再構築 | インデックスを再構築 |
| 表示 → 文字を大きく | 文字サイズを拡大 |
| 表示 → 文字を小さく | 文字サイズを縮小 |
| 表示 → 文字サイズリセット | 文字サイズを初期値に戻す |
| 設定 | 各種設定を変更 |
| ヘルプ → ヘルプを表示 | 操作ガイドを表示 |

## ファイル保存構造

```
電子帳簿保存/
└── {年}年/
    ├── index.csv
    ├── 支出情報/
    │   ├── 01.注文書・契約書/
    │   ├── 02.見積書(確定版)/
    │   ├── 03.請求書/
    │   └── 04.領収証/
    └── 収入情報/
        ├── 01.注文書・契約書/
        ├── 02.見積書(確定版)/
        ├── 03.請求書/
        └── 04.領収証/
```

ファイル名の形式: `{通し番号}_{発行日YYYYMMDD}_{金額}_{取引先名}.pdf`

例: `001_20240901_10800_株式会社サンプル.pdf`

## アップデート

### 自動アップデート

起動時に自動的に新しいバージョンをチェックします。

1. 新バージョンが検出されるとダイアログが表示されます
2. リリースノートを確認できます
3. **「今すぐダウンロード」** をクリックするとアプリ内でダウンロード開始（プログレスバー表示）
4. ダウンロード完了後、**「インストールして再起動」** をクリックすると自動インストール＆再起動
5. 特定バージョンをスキップすることも可能です

### 手動アップデート

1. [GitHub Releases](https://github.com/mozu93/denshi/releases) にアクセス
2. 最新版のインストーラーをダウンロード
3. インストーラーを実行してアップデート

## セキュリティ・法令対応

- **監査ログ**: 保存・編集・削除操作を自動記録（電子帳簿保存法 真実性確保）
- **ファイルハッシュ**: ファイルの改ざん検知
- ネットワークドライブ上での権限管理に依存
