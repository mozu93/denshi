# 電子帳簿保存システム

**バージョン**: v2.4.0
**最終更新**: 2026-05-23

## 概要

電子帳簿保存システムは、日本の電子帳簿保存法に対応したPyQt6ベースのデスクトップアプリケーションです。PDFファイルのOCR処理、メタデータ抽出、構造化された保存・検索機能を提供します。

## 主な機能

### 1. PDFファイル登録
- フォルダを選択してフォルダ内の全PDFを一括登録
- PDFファイルを個別に選択して登録
- PDFファイルのドラッグ&ドロップ対応
- OCRを使用した自動メタデータ抽出（発行日・金額・取引先名）
- 手動でのメタデータ編集が可能

### 2. ファイル検索
- 年度・取引区分・書類種別による検索
- 発行日・金額・取引先名・メモによる条件検索
- 複数条件の組み合わせ検索

### 3. データ管理
- CSV形式のインデックス（index.csv）でメタデータを管理
- 年度ごとのファイル整理
- メモ機能による追加情報の保存
- インデックス再構築時のメモ保持

### 4. ネットワーク対応
- ネットワークドライブ上での共有利用対応
- 複数ユーザーでの同時アクセス対応
- ロック機構によるデータ保護

### 5. 自動アップデート
- 起動時にGitHub Releasesを自動チェック
- アプリ内でインストーラーをダウンロード（プログレスバー表示）
- ダウンロード完了後、ワンクリックでインストール＆自動再起動

## インストール

### 方法1: インストーラーを使用（推奨）

1. [GitHub Releases](https://github.com/mozu93/denshi/releases) から最新版のインストーラーをダウンロード
2. インストーラーを実行し、画面の指示に従ってインストール
3. デスクトップのショートカットまたはスタートメニューからアプリケーションを起動

**必須環境**:
- Windows 10/11 (64bit)
- Tesseract OCRはインストーラーに同梱されます
- ネットワークドライブへのアクセス権

### 方法2: ソースコードから実行（開発者向け）

**必須環境**:
- Python 3.11以上
- Tesseract OCR（手動でインストール）
- ネットワークドライブへのアクセス権

```bash
pip install -r requirements.txt
python main.py
```

## 使用方法

### ファイル登録

1. **ファイル登録モード**タブを選択
2. PDFを追加する方法を選択:
   - メニュー **「ファイル」→「フォルダを開く」**: フォルダ内の全PDFを一括追加（フォルダは次回起動時まで記憶）
   - メニュー **「ファイル」→「ファイルを開く」**: PDFファイルを個別に選択
   - ウィンドウにPDFをドラッグ&ドロップ
3. リストに追加されたPDFを選択してメタデータを確認・編集
4. **「登録」** をクリック

### ファイル検索

1. **ファイル検索モード**タブを選択
2. 検索条件を入力（複数条件指定可能）
3. **「検索実行」** をクリック
4. 結果から **「編集」** をクリックしてデータを編集

### インデックス再構築

1. メニューの **「インデックス再構築」** をクリック
2. 確認メッセージで **「はい」** をクリック
3. ファイルシステムをスキャンして index.csv を再構築

**重要**: インデックス再構築時はメモが保持されます。

### 文字サイズの変更

メニュー **「表示」** から文字を大きく・小さく・リセットできます。

### 設定

メニュー **「設定」** からアプリの各種設定を変更できます。

## メニュー構成

| メニュー | 機能 |
|---|---|
| ファイル → フォルダを開く | フォルダ内の全PDFを一括登録 |
| ファイル → ファイルを開く | PDFを個別に選択して登録 |
| ファイル → 終了 | アプリを終了 |
| インデックス再構築 | インデックスを再構築 |
| 表示 → 文字を大きく | 文字サイズを拡大 |
| 表示 → 文字を小さく | 文字サイズを縮小 |
| 表示 → 文字サイズリセット | 文字サイズを初期値に戻す |
| 設定 | 各種設定を変更 |
| ヘルプ → ヘルプを表示 | 操作ガイドを表示 |

## 設定

### ハードコードされたパス設定

アプリケーションは以下のパスが固定化されています:

- **ルート保存ディレクトリ**: `\\yc-nas01\Ycci共通\000全体業務\000職員共通\070電子帳簿保存法関係\電子帳簿保存`
- **共有設定ファイル**: `\\yc-nas01\Ycci共通\000全体業務\000職員共通\070電子帳簿保存法関係\電子帳簿保存\config.ini`

パス設定画面では読み取り専用で表示されます。

## ファイル保存構造

```
電子帳簿保存/
└── {年}年/
    ├── index.csv
    ├── 支出情報/
    │   ├── 01.注文書・契約書/
    │   ├── 02.見積書(確定版)/
    │   ├── 03.請求書/
    │   └── 04.領収証/
    └── 収入情報/
        ├── 01.注文書・契約書/
        ├── 02.見積書(確定版)/
        ├── 03.請求書/
        └── 04.領収証/
```

ファイル名の形式: `{通し番号}_{発行日YYYYMMDD}_{金額}_{取引先名}.pdf`

例: `001_20240901_10800_株式会社サンプル.pdf`

## アップデート

### 自動アップデート

起動時に自動的に新しいバージョンをチェックします。

1. 新バージョンが検出されるとダイアログが表示されます
2. リリースノートを確認できます
3. **「今すぐダウンロード」** をクリックするとアプリ内でダウンロード開始（プログレスバー表示）
4. ダウンロード完了後、**「インストールして再起動」** をクリックすると自動インストール＆再起動
5. 特定バージョンをスキップすることも可能です

### 手動アップデート

1. [GitHub Releases](https://github.com/mozu93/denshi/releases) にアクセス
2. 最新版のインストーラーをダウンロード
3. インストーラーを実行してアップデート
