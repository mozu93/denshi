# 電子帳簿保存システム

電子帳簿保存法に対応した電子取引データの管理システム

## 概要

2024年1月から義務化された改正電子帳簿保存法に対応するため、電子取引データを規則に従ってファイル名変更し、検索性を確保して保存するためのPyQt6ベースのGUIアプリケーションです。

### 主な機能

- **PDFプレビュー機能**: ファイルの内容を確認しながら登録作業
- **ドラッグ&ドロップ対応**: 複数PDFファイルを簡単に追加
- **自動ファイル名生成**: `通し番号_発行日_金額_取引先名.pdf` 形式で自動命名
- **OCR文字認識機能**: PDFから金額・日付・取引先名を自動抽出（選択領域対応）
- **和暦自動変換**: 令和6年9月1日 → 20240901 形式に自動変換
- **年度別フォルダ管理**: 年度ごとに自動的にフォルダを作成・整理
- **メタデータ管理**: CSVベースのインデックスファイルで検索性確保
- **設定機能**: 保存先、書類分類、OCRエンジンパスのカスタマイズ
- **ヘルプ機能**: アプリケーションの利用方法に関するガイドを表示
- **起動ガイド**: アプリケーション起動時に利用方法のヒントを表示（「今後表示しない」オプション付き）
- **書類種別管理**: 設定ダイアログ内で支出・収入別に書類種別を追加・編集・削除（関連ファイルが存在する場合は削除制限あり）
- **検索機能強化**: 年度をプルダウンから選択可能にし、検索フィールドでのEnterキー押下で検索実行
- **堅牢性の向上**: 包括的なエラーハンドリングと入力値検証により、予期せぬクラッシュを防止し、安定した操作を実現
- **パフォーマンス改善**: アプリケーション起動時にOCRエンジンを事前読み込みし、初回認識時の待機時間を短縮

## 動作環境

- **Python**: 3.11+
- **GUI Framework**: PyQt6
- **OCR Engine**: Tesseract OCR
- **PDF処理**: PyMuPDF (fitz)

## セットアップ

### 1. 必要な依存関係のインストール

```bash
pip install -r requirements.txt
```

### 2. Tesseract OCRのインストール

#### Windows
1.  **インストーラーのダウンロード:**
    [Tesseract OCRの公式ダウンロードページ](https://tesseract-ocr.github.io/tessdoc/Downloads.html) から、Windows向けの64-bitインストーラー（例: `tesseract-ocr-w64-setup-vX.XX.XX.exe`）をダウンロードします。
2.  **インストール:**
    インストーラーを実行し、指示に従ってインストールを進めます。
    *   言語選択では「English」を選択します。
    *   「Additional language data」の項目で、「Japanese script」「Japanese vertical script」「Japanese」「Japanese (vertical)」にチェックを入れて、日本語言語データをインストールします。
3.  **環境変数PATHの設定:**
    インストールが完了したら、Tesseract-OCRがインストールされたディレクトリ（例: `C:\ Program Files\Tesseract-OCR`）をシステムの環境変数PATHに追加します。
    *   「コントロールパネル」→「システムとセキュリティ」→「システム」→「システムの詳細設定」→「環境変数」を開きます。
    *   「Path」を選択し、「編集」をクリックします。
    *   Tesseract-OCRのインストールパス（例: `C:\ Program Files\Tesseract-OCR`）を追加します。
    *   **補足**: 環境変数PATHを設定する代わりに、アプリケーション起動後にメニューの「ツール」→「設定」からTesseractの実行ファイルパスを直接指定することも可能です。
4.  **動作確認:**
    コマンドプロンプトを開き、`tesseract --version` と入力してTesseractが正しくインストールされているか確認します。
    また、`tesseract <画像ファイル名> stdout -l jpn` と入力して、日本語の画像認識が機能するかテストできます。

#### macOS
```bash
brew install tesseract tesseract-lang
```

#### Ubuntu/Debian
```bash
sudo apt-get install tesseract-ocr tesseract-ocr-jpn
```

### 3. アプリケーション起動

```bash
python main.py
```

### 4. 実行可能ファイルの作成 (Windows)

PyInstallerを使用して、アプリケーションを単一の実行可能ファイルにパッケージ化できます。

```bash
pyinstaller --noconsole --onefile --add-data "config.ini;. " --add-data "電子帳簿保存;電子帳簿保存" main.py
```
生成された `main.exe` は `dist` フォルダ内にあります。

## 画面構成

### メインウィンドウ
- **メニューバー**: ファイル操作・ツール機能・ヘルプへのアクセス
- **タブ切替**: 「ファイル登録モード」「ファイル検索モード」
- **ステータスバー**: 処理状況やメッセージの表示

### ファイル登録モード
- **左側パネル**:
  - 登録ファイル一覧
  - データ入力エリア（発行日、金額、取引先名、メモ）
  - 入力ガイド: PDFプレビューを見て直接入力するか、該当箇所を赤い四角で囲んで読み取ってください。
- **右側パネル**:
  - PDFプレビュー（ズーム・ページ切替対応）
  - OCR領域選択機能
  - ファイル名プレビュー

### ファイル検索モード
- **検索条件**: 年度（プルダウン選択）、書類種別、取引先名、発行日、金額、メモで絞り込み可能
- **検索結果**: テーブル形式で表示、PDFを開く、編集、削除が可能

## 使用方法

### ファイル登録の流れ

1. **PDFファイルの追加**
   - メニューから「ファイル」→「PDFを開く」を選択
   - または、メインウィンドウにPDFファイルをドラッグ&ドロップ

2. **データ入力**
   - ファイルリストからPDFを選択してプレビュー表示
   - OCR機能で自動抽出（領域選択可能）または手動で、発行日、金額、取引先名、メモを入力・修正
   - 入力ガイドに従って操作してください。

3. **保存**
   - 「保存して次へ」ボタンをクリック
   - 設定されたルートフォルダ配下の年度別フォルダに自動保存

### OCR機能の使い方
- PDFプレビュー上でマウスドラッグで領域選択
- 選択した領域に対してOCR処理を実行
- 認識結果が該当するフィールドに自動入力

### ファイル検索の使い方
1. **検索条件の入力**: 年度をプルダウンから選択し、必要に応じて書類種別、取引先名、発行日、金額、メモを入力します。
2. **検索実行**: 「検索実行」ボタンをクリックするか、検索フィールドでEnterキーを押します。
3. **結果の操作**: 検索結果の行をダブルクリックすると関連PDFが開きます。「編集」ボタンで情報を修正、「削除」ボタンでファイルとメタデータを削除できます。

### 設定の変更
- メニューから「ツール」→「設定」を選択します。
- **ルート保存ディレクトリ**: PDFファイルの保存先フォルダを変更できます。
- **Tesseract OCRパス**: Tesseractがインストールされているパスを手動で設定できます。環境変数PATHにTesseractが登録されていない場合に有効です。
- **書類種別管理**: 「支出」と「収入」のタブで、それぞれに紐づく書類種別（例: 請求書、領収証）を追加・編集・削除できます。
  - 「追加」ボタンで新しい書類種別を登録します。
  - 削除したい書類種別を選択し、「選択を削除」ボタンをクリックします。
  - **注意**: 関連するファイルがフォルダ内に存在する場合、書類種別は削除できません。

## 設定ファイル

`config.ini` で以下の設定をカスタマイズできます：

```ini
[Paths]
root_save_directory = 電子帳簿保存

[Tesseract]
path = C:\ Program Files\Tesseract-OCR\tesseract.exe

[FolderNames_Expenditure]
order = 01.注文書・契約書
estimate = 02.見積書(確定版)
invoice = 03.請求書
receipt = 04.領収証
transfer_details = 05.振込明細
withdrawal_notice = 06.引落通知
other_expenditure = 07.その他

[FolderNames_Income]
order = 01.注文書・契約書
estimate = 02.見積書(確定版)
invoice = 03.請求書
receipt = 04.領収証
transfer_notice = 05.振込通知
other_income = 06.その他

[LastInputs]
year = 2025
doc_type_index = 2

[Settings]
show_startup_guide = True
```

## トラブルシューティング

### OCRが正常に動作しない場合
1. メニューの「ツール」→「設定」からTesseract OCRの実行ファイル（tesseract.exe）のパスが正しく設定されているか確認します。
2. Tesseractが正しくインストールされているか確認（環境変数PATHに登録する場合）。
3. 日本語言語データ（jpn.traineddata）がインストールされているか確認。
4. 画像の解像度や品質を確認。

### ファイルが保存されない場合
1. 保存先ディレクトリの書き込み権限を確認
2. ディスク容量が十分にあるか確認
3. ファイル名に使用できない文字が含まれていないか確認
