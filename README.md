# 電子帳簿保存システム

**バージョン**: v2.0.0
**最終更新**: 2026-02-20

## 📋 概要

電子帳簿保存システムは、日本の電子帳簿保存法に対応したPyQt6ベースのデスクトップアプリケーションです。PDFファイルの OCR 処理、メタデータ抽出、構造化された保存・検索機能を提供します。

## ✨ 主な機能

### 1. PDFファイル登録
- PDFファイルのドラッグ&ドロップ対応
- OCR を使用した自動メタデータ抽出
- 発行日、金額、取引先名の自動認識
- 手動でのメタデータ編集が可能

### 2. ファイル検索
- 年度、取引区分、書類種別による検索
- 発行日、金額、取引先名による条件検索
- メモフィールドでの検索対応
- 複数条件の組み合わせ検索

### 3. データ管理
- CSV形式のインデックス（index.csv）で メタデータを管理
- 年度ごとのファイル整理
- メモ機能による追加情報の保存

### 4. ネットワーク対応
- ネットワークドライブ上での共有利用対応
- 複数ユーザーでの同時アクセス対応
- ロック機構によるデータ保護

## 🚀 インストール

### 方法1: インストーラーを使用（推奨）

1. [GitHub Releases](https://github.com/your-username/denshi/releases) から最新版のインストーラーをダウンロード
   - ファイル名: `DenshiChobohozoSystem_v2.0.0_setup.exe`
2. インストーラーを実行
3. 画面の指示に従ってインストール
4. デスクトップアイコンまたはスタートメニューからアプリケーションを起動

**必須環境**:
- Windows 10/11 (64bit)
- Tesseract OCRは自動的にインストールされます
- ネットワークドライブへのアクセス権

### 方法2: ソースコードから実行（開発者向け）

**必須環境**:
- Python 3.11以上
- Tesseract OCR（手動でインストール）
- ネットワークドライブへのアクセス権

**依存パッケージ**:

```bash
pip install -r requirements.txt
```

**起動方法**:

```bash
# コマンドラインから起動
python main.py

# またはダブルクリック起動
起動.bat
```

## 📖 使用方法

### ファイル登録

1. **ファイル登録モード**タブを選択
2. **「PDFを開く」** または ドラッグ&ドロップでPDFを選択
3. メタデータを確認・編集
4. **「登録」** をクリック

### ファイル検索

1. **ファイル検索モード**タブを選択
2. 検索条件を入力（複数条件指定可能）
3. **「検索実行」** をクリック
4. 結果から **「編集」** をクリックしてデータを編集

### インデックス再構築

1. **ツール** → **「インデックス再構築」**
2. 確認メッセージで **「はい」** をクリック
3. ファイルシステムをスキャンしてindex.csvを再構築

**重要**: インデックス再構築時はメモが保持されます。
